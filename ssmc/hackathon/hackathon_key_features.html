동료평가 (HACK ARENA) 배점 구조 제외 — 임의평가 항목으로만 활용 참가자 블라인드 1:1 배틀 방식, 승/패/비김 집계
AI 심사 상세 정책
🤖
LLM 다수결 방식
  • GPT-4o / Claude / Gemini 3개 모델 고정 운영
  • 3개 모델의 점수를 다수결로 최종 점수 산출
  • 전원 다른 점수일 경우 운영자가 관대/중립(기본)/엄격 선택
  • LLM별 점수 + 근거 어드민에서 상세 확인 가능
⚙️
심사 실행 방식
  • 수동 실시 기본 — 운영자가 심사 실시 버튼 클릭
  • 일배치 자동 실행 옵션 선택 가능 (어드민 설정)
  • 전처리는 파일 등록 즉시 자동 가동 (별도 트리거 불필요)
  • AI 심사 결과는 운영자 승인 후 리더보드 반영
📊
심사 결과 관리
  • 루브릭 버전별 심사 결과 누적 이력 관리 (v1.0 / v2.0 등)
  • LLM 심사결과 탭 + 전처리 데이터 탭 분리 제공
  • 카테고리별 등급 + 점수 테이블, CSV 다운로드
  • 리더보드 UX: "점수는 기준 변경에 따라 전일 대비 달라질 수 있습니다"
📄
리포트 자동 생성
  • 본선 진출자 확정 클릭 시 즉시 자동 생성 (수동 트리거 없음)
  • 심사위원용 리포트 / 참가자 개인 리포트 분리
  • 참가자는 결과 확인 화면에서 조회 및 다운로드/인쇄
  • 확정 알럿: "루브릭 수정 불가, 리포트 자동 생성 진행"
⚠️
루브릭 수정 시 전체 재심사가 진행되며 리더보드 점수가 변동될 수 있습니다. 수정 가능 횟수는 루브릭 수정 + 테스트 합산 최대 10회로 제한됩니다.
02
해커톤 대회설정
운영자가 대회 전 설정해야 하는 전체 항목. 기본 정보 · 트랙 설정 · 심사 설정 · 공개/알림 4개 탭으로 구성.
대회설정 탭 구성
1
기본 정보
배너/썸네일 업로드, 대회소개 (HTML 에디터), 보상/혜택 내용, 일정 설정 (각 단계별 시작~종료일)
대회 시작 후 일부 항목 수정 제한
2
트랙 설정
참가 유형: Basic(MVP톤) / Custom 라디오 선택 (아이디어톤/MVP톤 chip 표기 전체 삭제)
트랙별 제출 항목 관리 — 항목 추가 모달로 구성 (PDF / MD / URL 파일 타입 설정)
3
심사 설정
탭 3개 구성: 심사단계 설정 / 심사기준·루브릭(Step1~3-3) / 심사기준 다운로드
AI 심사 LLM 다수결 예외처리, 배점 구조 설정 (AI심사 + 임의평가), 동료투표 활성화 여부
대회 시작 후 프리징 (본선 확정 전까지 루브릭 수정 가능, 최대 10회)
4
공개/알림
갤러리 노출 시점: 본선 진행 중 / 최종 수상자 발표 후 선택
AI 심사 결과 노출 방식 설정, 갤러리 미리보기 버튼
메일링 설정: 발송 이메일 내용 설정 + 발송 이력 탭
주요 정책
항목내용
대회 유형Basic(MVP톤) / Custom 2가지 유지. 아이디어톤/MVP톤 chip 표기 어드민·프론트 전체 삭제
프리징 기준대회 시작 후 심사 설정 전체 수정 불가. 루브릭만 본선 확정 전까지 최대 10회 허용
갤러리 노출하트(동료평가) 기능 삭제. 아카이빙 개념. 노출 시점 운영자 설정 (본선 중 / 수상 후)
데이터 보관운영 종료 후 +1개월 유지, 이후 파기
임의평가운영자가 항목명 직접 설정. 동료평가 배틀 결과를 임의평가로 활용 가능
ℹ️
대회설정은 킥오프 전 운영자가 사전에 완료해야 합니다. 대회 시작 이후 심사단계 설정과 배점 구조는 수정이 불가합니다.

Step 3-1 — 루브릭 점검 AI 자동
포지큐브 API를 호출해 루브릭의 명확성·일관성을 자동 분석한다.
지표별 수정 필요 / 검토 권장 / 참고 3단계로 분류.
현재 문구 vs AI 제안 문구 나란히 비교, 운영자가 무시 / 직접 수정 / 제안대로 수정 중 선택.
선택 사항 — 점검 여부는 운영자가 결정.
OP
Step 3-2 — 심사 테스트 운영자
가상 팀이름 + 가상 제출 파일로 AI 심사를 미리 실행해 루브릭 품질을 확인한다.
테스트 케이스 복수 추가 가능. 테스트 실행 시 즉시 심사 진행.
잔여 횟수 표시 (최대 10회) — 루브릭 수정 + 테스트 합산 카운트.
✓
Step 3-3 — 루브릭 확정 운영자
점검 + 테스트 완료 후 최종 확정. 버전 이력 표시 (v1.0 적용 중 → v1.1 변경 예정).
AI 심사 전: [이대로 확정하기] 버튼 활성.
AI 심사 후 수정 시: 알럿 — "전체 재심사 진행, 리더보드 점수 변동 가능"
본선 확정 후: 확정 버튼 비활성 (수정 불가).
제약 조건 및 정책
항목내용
수정 가능 기간본선 진출자 확정 전까지 허용
최대 횟수루브릭 수정 + 테스트 실행 합산 최대 10회
재심사 트리거루브릭 수정 시 전체 재심사 자동 진행, 리더보드 점수 변동 가능
버전 관리변경 이력 누적 저장 (v1.0 → v1.1). 심사 결과 관리 화면에서 버전별 조회 가능
MD/URL 제출 시루브릭 8번 항목 자동 추가 (어드민 연동)
포지큐브 연동파라미터 스펙 확정 필요 (개발팀 신동진 확인 대기)
⚠️
루브릭 점검(Step 3-1)은 선택 사항이지만, 심사 테스트(Step 3-2)는 잔여 횟수를 소진합니다. 본선 확정 후에는 루브릭 수정이 불가하므로 대회 시작 전 충분히 검증해야 합니다.
