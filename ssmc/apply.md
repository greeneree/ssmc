## 2. 수강생 풀 (팀원 검색 범위)

### 배경
해커톤은 기업이 멀티캠퍼스에 단체 수강을 신청하고,
소속 직원들이 동일 과정(course_id)의 학습자로 등록된 구조.

예시:
한화오션 (기업)
└── 멀티캠퍼스 단체 수강 신청
└── 마케팅팀 직원 → AI Studio 학습자 등록
└── LLM 파인튜닝 강좌 수강생 = 팀원 검색 풀

### 팀원 검색 범위
- **동일 과정(course_id) 수강생 목록 내에서만 검색**
- 외부 조직도 / 별도 DB 연동 없음
- 같은 강좌를 듣는 수강생이면 소속과 무관하게 검색 및 초대 가능
- API: 기존 수강생 목록 API 활용 (course_id 기준 필터)

## 3. 참여신청 폼 (Step 1)

### 3-1. 기본 정보 입력

| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 팀 이름 | text input | ✅ | 최대 20자 / 중복 불가 (실시간 체크) |
| 해커톤 유형 | radio | ✅ | 아이디어톤 / MVP톤 |
| 참가 주제 | textarea | ✅ | 최대 200자 / 아이디어 한 줄 요약 |
| 교육 지원 필요 여부 | toggle (Y/N) | - | Y 선택 시 텍스트 입력 필드 활성화 |
| 기술 멘토링 필요 여부 | toggle (Y/N) | - | Y 선택 시 필요 영역 텍스트 입력 필드 활성화 |

### 3-2. 유효성 검사
- 팀 이름 중복: 입력 완료(onBlur) 시 실시간 체크
  - 중복: "이미 사용 중인 팀 이름입니다."
  - 사용 가능: "사용 가능한 팀 이름입니다."
- 필수항목 미입력 시 [다음] 버튼 비활성화

## 4. 팀 구성 (Step 2)

### 4-1. 팀원 추가 방식
참가자(팀장)가 직접 같은 과정 수강생을 검색하여 팀원 추가

**검색 및 추가 플로우:**
1. 이름으로 검색 (course_id 기준 수강생 목록 내)
2. 검색 결과 드롭다운 노출
   - 이름 / 소속(기업명 or 부서) 표시
   - 이미 다른 팀 소속인 경우: 비활성 + "참가 중" 뱃지
3. 클릭하여 팀원 추가
4. 추가된 팀원 카드 형태 표시 (이름, 소속, 삭제 버튼)

**팀 구성 규칙:**
- 팀장: 신청자 본인 자동 설정 (변경 불가)
- 최소: 1인 (개인 참가 가능)
- 최대: 운영자 설정값 기준
- 최대 인원 초과 시: "팀 인원은 최대 N명입니다."
- 이미 다른 팀 소속 초대 시: "이미 다른 팀에 참가 중인 멤버입니다."

**팀원 구성 영역 UI (AI Studio 팀빌딩 모달 참고):**

┌─────────────────────────────────────────┐
│ 팀원 검색 (같은 과정 수강생 중 검색)      │
│ [이름 검색...            ]  [+ 추가]     │
│  ↓ 검색 결과 드롭다운                    │
│  ┌──────────────────────────────┐       │
│  │ 이영희  마케팅팀              │       │
│  │ 박민수  개발팀       참가 중  │(비활성)│
│  │ 최유진  인사팀                │       │
│  └──────────────────────────────┘       │
│                                         │
│ 현재 팀 구성 (2 / 4명)                  │
│ ┌──────────┐  ┌──────────┐             │
│ │ 김팀장   │  │ 이영희   │ ✕           │
│ │ (팀장)   │  │ 마케팅팀  │             │
│ └──────────┘  └──────────┘             │
└─────────────────────────────────────────┘

### 4-2. 신청 완료 조건
- 기본 정보 + 팀원 구성 완료 시 [신청 완료] 버튼 활성화
- 제출 후 확인 토스트: "참가 신청이 완료되었습니다."
- 신청 완료 후 재진입 시 → 팀 관리 화면으로 이동

## 5. 팀 관리 화면 (신청 완료 후)

### 5-1. 수정 가능 항목 (신청 기간 내)
- 팀 이름
- 참가 주제
- 교육/멘토링 수요
- 팀원 추가/삭제

### 5-2. 수정 불가 항목
- 팀장 (본인 고정)
- 해커톤 유형 (신청 후 변경 불가)

### 5-3. 팀원 상태 처리
- 팀원이 탈퇴/삭제된 경우: "탈퇴됨" 뱃지 + 재초대 버튼 노출
- 팀장이 팀원 강제 삭제 가능 (삭제 시 해당 팀원에게 알림)

### 5-4. 참가 취소
- [참가 취소] 버튼 하단 노출 (신청 기간 내)
- 확인 다이얼로그:
  "참가를 취소하면 팀 정보가 모두 삭제됩니다. 취소하시겠습니까?"
- 취소 완료 시 참여신청 폼으로 초기화
